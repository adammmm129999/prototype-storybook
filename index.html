互動設計與 UI 元件規格

低階｜外觀描述

目標是命名可直接觀察的線索，不要求完整句。

  • 提示：顏色、形狀、大小、觸感、明暗或透明度
  • 例：「你看到什麼顏色？」
  • 回應：肯定原詞，接上當頁的場景與焦點

中階｜因果推理

從「看見什麼」走向「為什麼、接下來會怎樣」。

  • 提示：原因、結果、角色感受、解決方法
  • 例：「塑膠袋卡住螃蟹，牠可能會怎麼辦？」
  • 回應：肯定推理，延伸行動與後果

高階｜美感想像

鼓勵個人聯想、感官語言與創作，不評分對錯。

  • 提示：如果你在海底、想為畫面加聲音或顏色
  • 例：「你會替這片海加上什麼光？」
  • 回應：把孩子想像轉成畫面描述

回答延伸規則｜短詞也能接住

辨認詞語類型 → 讀取當頁場景 → 正向肯定 → 故事擴句 → 短暫視覺回饋

  • 「冰冰的」→把詞放進當頁海流情境，描述波波感受到涼涼水流；畫面出現冷色水波。
  • 「黑色的」→連到當頁焦點；第三頁塑膠瓶蓋呈現柔和水光，只有漁網頁才使用銀白金屬反光。
  • 「綠綠的」→加入海草或珊瑚的顏色，畫面暫時泛綠光；「圓圓的／小小的」→增加上升泡泡；「濕濕的」→依當頁情節呈現潮水水痕或雨滴，不把下雨套到無雨場景。
  • 不認得的詞也會被肯定，並放回當頁情境當成新線索；每次只加一個可選追問。效果短暫、非獎懲、不遮住故事。

主要 UI 元件

  • 繪本舞台：插圖、章節標題、文字、頁碼與進度條
  • 難度切換：三個常駐按鈕，家長可隨時切換
  • 提問卡：一題、可選提示詞、文字輸入、語音朗讀
  • 回饋區：肯定、故事延伸、可選追問、動態特效
  • 導航：上一頁、下一頁、章節點點

節奏與照顧者支援

  • 只在 1、3、5、7、9 章設置停頓提問，避免每頁打斷閱讀
  • 孩子可跳過、口答或由家長代輸入；不顯示分數
  • 語音朗讀由家長手動開啟，預設關閉
  • 支援手機版、鍵盤操作與減少動態效果偏好

家長共讀指南

這個故事把閱讀拆成「看見線索、理解原因、自由想像」三種聊天方式。請依孩子當下興趣選擇；可以只說一個詞，也可以完全跳過提問。

  • 看一看：「你注意到什麼顏色／形狀？」等孩子先說，再把詞放回情境。
  • 想原因：「你覺得為什麼會這樣？接下來可能發生什麼？」接受多種合理想法。
  • 想像力：「如果你能替這片海加一種光或聲音，你會選什麼？」不糾正想像。
  • 回應孩子：先接住內容，例如「你看到黑黑的網了」，再補一段故事，最後只加一個選擇性的追問。
  • 短詞、沉默、跳過都不是錯誤。這裡沒有評分、錄音或答案排名。
